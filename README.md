## Technologies Explored

This portfolio showcases hands-on experience in building scalable server-side systems using:

*   **Node.js & Express.js** — Core runtime and frameworks for asynchronous JavaScript backend environments.
*   **Python (FastAPI, Django & Flask)** — High-performance REST APIs, batteries-included MVT web apps, and lightweight WSGI services.
*   **Databases (PostgreSQL, MongoDB & SQLite)** — Relational schemas, JSONB querying, SQLAlchemy ORM, and Mongoose ODM.
*   **EJS & Jinja2** — Templating engines utilized for generating dynamic server-rendered HTML pages.
*   **Docker & Git** — Containerized application deployment and version control management.
